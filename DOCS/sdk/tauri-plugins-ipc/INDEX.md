## Curator notes

- Kotlin plugin: class annotated `@TauriPlugin`, extending `Plugin(activity)`; methods annotated `@Command` taking `invoke: Invoke`, resolving with `invoke.resolve(JSObject)` / `invoke.reject(...)`; args via `@InvokeArg` classes and `invoke.parseArgs(...)` → `develop-mobile.md`.
- Rust side registers the Kotlin class with `api.register_android_plugin("<package>", "<Class>")` and calls it with `PluginHandle::run_mobile_plugin("<command>", payload)` → `plugin-template-mobile-rs.md` (CLI plugin template, tauri `dev` @ 2e23492ab9bc). Kotlin counterpart → `plugin-template-ExamplePlugin-kt.md`.
- App commands: `#[tauri::command]` + `.invoke_handler(tauri::generate_handler![...])`; only **one** `invoke_handler` call is honoured (list all commands in one macro) → `calling-rust.md`.
- Capabilities: JSON/TOML files in `src-tauri/capabilities/` grant permissions (`<plugin>:default`, `core:default`, …) per window/webview → `capabilities.md`, `permissions.md`.
